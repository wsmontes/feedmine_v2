## Decisions

- Preserve canonical source/target/binding identities, enabled/revoked fences, one traversal, one acquisition coordinator, one media owner and one editorial selector. Source taxonomy is exploration evidence, not an item's topic. Hostname is not provider identity: independent YouTubers do not become one provider. Unknown providers/subjects remain unknown.
- New selection behavior gets revision **7**. Keep v2–v6 publication/history semantics; unsupported future versions remain unsupported. Ordinary warm restore first shows the same edition/anchor without HTTP. At the next existing production opportunity, apply v7 to **new segments of the existing edition**, using its complete frozen history, without resetting the cursor, cloning/reordering its prefix or replacing unseen published cards. Introduce an explicit append-policy transition in the existing publication authority (currently edition/revision fences require the same policy); persist its boundary atomically. Do not reinterpret the old edition revision or leave existing readers permanently on v6. Test reopen on both sides of that boundary before host cutover.
- Declared item playback determines type (`none` is known no-playback; `nil` unknown). Enforce single-type and paired-type filters before readiness/selection; never infer item type from source kind/cover. A video card retains its badge and genuine origin action, never the audio-only AVPlayer. Forum cannot be inferred from no-playback: unsupported forum-only supply stays honestly unavailable.
- Language precedence: actual Atom entry `xml:lang`, then inherited feed `xml:lang`; entry override/explicit empty declaration must not inherit an incompatible language. Preserve canonical declarations, never fill them from catalogue/registration/reader choices. For undeclared YouTube items, add an **abstaining, filter-independent local item-text language resolver** at the bounded candidate boundary, with typed evidence (`declared`/`detected from this item's text`/`unknown`), revision/text identity and diagnostic provenance. Use the item's actual readable title/description, including genuine media-group description when provided. Production resolver lives in Composition using Apple's language recognition; tests inject deterministic evidence, not guessed language labels. Source language narrows acquisition and cross-checks contradictions; it is **not sufficient item-language proof**. Short/ambiguous text, contradictory text/declarations, incompatible script or unresolved evidence fails a strict language criterion. Missing metadata alone never passes. Calibrate abstention against the captured Portuguese and Japanese-script samples; do not weaken filters to obtain video counts.
- Rich new feeds wait for broad **ready supplier** coverage before first publication. The surface's three-source/image floors cannot substitute for this. Genuine sparse/source-only contexts may publish their finite good supply; timeouts/partial releases remain partial, not quality PASS. Pending declared images stay suspended; legitimate text-only stories count as ready.
